# ভেন্ডর ম্যানেজার — চারু

## চালু করুন
Python 3.10+ ইনস্টল করা কম্পিউটারে:

```bash
pip install -r requirements.txt
python app.py
```

ব্রাউজারে `http://localhost:5000` খুলুন। প্রথম রেজিস্ট্রেশনকারী স্বয়ংক্রিয়ভাবে অ্যাডমিন; পরের ব্যবহারকারীরা অনুমোদনের অপেক্ষায় থাকবেন।

## মোবাইল ও কম্পিউটারে ইনস্টল
এটি একটি PWA। নিরাপদ HTTPS সার্ভারে হোস্ট করে Chrome/Edge এর **Install app** বা **Add to Home Screen** ব্যবহার করুন। একাধিক ডিভাইস থেকে একই তথ্য ব্যবহার করতে সার্ভারটি অনলাইনে চলতে হবে এবং `DATABASE_PATH` দিয়ে স্থায়ী SQLite ডেটা স্টোরেজ দিতে হবে। `SECRET_KEY` পরিবেশ ভেরিয়েবল নির্ধারণ করুন। শুধু HTML ফাইল খুলে বা ZIP ইনস্টল করলেই সার্ভার/শেয়ার্ড লগইন চালু হবে না।

## PDF
ব্যাংক PDF ট্যাব → বছর/মাস/ব্যাংক নির্বাচন → Print / Save as PDF। বাংলা ফন্ট সমর্থিত ব্রাউজার ব্যবহার করুন।

## ডেটা ও সতর্কতা
মূল Excel ফাইল থেকে ভেন্ডর এবং ২০২৬ সালের মাসভিত্তিক পেমেন্ট রেকর্ড আনা হয়েছে। মূল ফাইলে খালি বা অনুপস্থিত ঘর ফাঁকা রাখা হয়েছে। Supplier Info.xls পুরোনো ফরম্যাটের হওয়ায় এই সংস্করণে স্বয়ংক্রিয় আমদানি হয়নি। ব্যাংক অ্যাকাউন্ট তথ্য যাচাই না করে অর্থ স্থানান্তর করবেন না।

এটি কাজের প্রাথমিক সংস্করণ। ইন্টারনেটে প্রকাশ করার আগে HTTPS, ব্যাকআপ, লগিং, নিরাপত্তা পর্যালোচনা এবং প্রোডাকশন WSGI সার্ভার কনফিগার করুন। অফলাইনে সম্পূর্ণ ডেটা সম্পাদনা সমর্থিত নয়।
